# Admin Panel

[Розгорнута версія](https://kostin-cn.github.io/admin-panel/)

## Архітектурні рішення

### Структура компонентів
Проект використовує модульну структуру компонентів з розділенням на:
- `views` - головні сторінки додатку
- `components/common` - загальні компоненти (хедер, футер, сайдбар)
- `components/[feature]` - компоненти для конкретних функціональних блоків
- `layouts` - шаблони сторінок

### Composables
Використовуються для винесення логіки з компонентів:
- `useAuthActions` - авторизація
- `useCrudActions` - CRUD-операції
- `useTheme` - перемикання тем
- `use[Entity]Actions` - специфічні для сутностей дії

### API-шар
- `api/client.ts` - конфігурація Axios
- `api/[entity].ts` - специфічні для сутностей API-методи
- `api/mockAdapter.ts` - мок-адаптер для роботи без бекенду

## Локальний запуск

1. Клонуйте репозиторій:
   ```sh
   git clone https://github.com/kostin-cn/admin-panel.git
   ```

2. Встановіть залежності:
   ```sh
   npm install
   ```

3. Запустіть сервер розробки:
   ```sh
   npm run dev
   ```

## Мок-адаптер

Мок-адаптер симулює роботу з бекендом, зберігаючи дані в localStorage. Це дозволяє розробляти та тестувати додаток без реального бекенду.

### Основні особливості мок-адаптера:

1. Зберігає дані в localStorage

2. Реалізує основні CRUD-операції

3. Додає випадкові затримки для симуляції мережевого трафіку

4. Реалізує каскадне видалення (при видаленні категорії видаляються пов'язані статті)


Мок-адаптер автоматично підключається в режимі розробки через конфігурацію Axios.
